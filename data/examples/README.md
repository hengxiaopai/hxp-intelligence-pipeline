# Example Data

This directory contains deterministic fixtures for validating the HXP Intelligence Pipeline without making network requests.

## Core files

- `briefing.example.json`: baseline daily briefing structure.
- `source.example.json`: synthetic source used by the baseline briefing.
- `manifest.example.json`: generated asset manifest.
- `candidate.example.json`: candidate event structure.
- `candidate-source.example.json`: source record referenced by the candidate event.
- `dedup-index.example.json`: 3/7/30 day history index.

## Phase 3.1 editorial files

The following files are generated by `scripts/generate_editorial_examples.py`:

- `candidate-pool.example.json`: candidates with dedup and editorial annotations.
- `editorial-scores.example.json`: explainable scores and admission actions.
- `briefing-assembled.example.json`: assembled daily briefing.
- `briefing-assembled.example.md`: public Markdown without the internal rejection pool.

Regenerate and verify reproducibility:

```bash
python scripts/generate_editorial_examples.py
git diff --exit-code -- data/examples/
```

## Validate

```bash
python scripts/validate.py --examples
python scripts/validate.py \
  --schema schemas/candidate.schema.json \
  --data data/examples/candidate.example.json
python scripts/validate.py \
  --schema schemas/editorial-score.schema.json \
  --data data/examples/editorial-scores.example.json
python scripts/validate.py \
  --schema schemas/briefing.schema.json \
  --data data/examples/briefing-assembled.example.json
python scripts/source_registry.py --validate
python scripts/validate_candidate.py
python -m unittest discover -s tests -v
```

Examples are test fixtures. They are not automatically approved for public publication.
