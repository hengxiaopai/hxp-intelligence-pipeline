# 珩小派多元情报视觉规范

## 品牌定位

- 品牌：珩小派 / HENGXIAOPAI
- 内容定位：一人公司情报雷达与 AI Research Studio 情报资产
- 视觉气质：Quiet Intelligence + Futuristic Editorial
- 当前海报主方向：明亮蓝白科技、清晰、克制、可长期复用

不得将海报做成电商促销、赛博朋克、游戏界面、光污染或通用 AI 模板。玻璃效果只用于轻量信息层级，不使用过度透明、模糊和高亮描边。

## 画布与安全区

- 母版：SVG
- 发布资产：PNG
- 画布：2160×3840
- 比例：9:16
- 左右安全边距：144 px
- 顶部安全边距：120 px
- 底部安全边距：120 px
- 卡片圆角：42 px
- 默认描边：2 px

所有尺寸由 `config/visual-theme.json` 管理，渲染器不得根据内容随机改变版式。

## 固定结构

### 详情海报

1. 左上：`珩小派多元情报｜今日焦点 XX`
2. 右上：正式 Logo
3. 日期与 `XX / 总数`
4. 主标题与副标题
5. 信息类型、置信度标签
6. 无文字主题主视觉
7. 一句话摘要与置信度依据
8. `01 为什么重要`
9. `02 后续关注`
10. 可转化方向、来源简称和品牌尾注

### 总览海报

1. `珩小派多元情报｜今日总览`
2. 日期与 `OVERVIEW`
3. 实际焦点数量，不固定写“今日 7 大焦点”
4. 今日判断
5. 全部正式入选焦点
6. 今日主线
7. 三个内容机会
8. 产品机会与风险提醒
9. `珩小派｜一人公司情报雷达`

内部淘汰候选不得进入总览海报。

## 中文排版

- 主标题最多 2 行
- 副标题最多 2 行
- 摘要最多 4 行
- 每个分析区最多 3 条
- 每条分析最多 2 行
- 来源最多 2 行
- 标题过长时优先重新提炼，不允许无限缩小字号
- 固定模板使用显示宽度计算，同时处理中文、英文和数字
- 出现省略号或溢出标记时，正式质检失败

字体只引用系统安装字体：

1. Noto Sans CJK SC
2. Source Han Sans SC
3. Microsoft YaHei
4. PingFang SC

仓库不保存或分发字体文件。

## 品牌与资产边界

- Logo 必须来自主理人批准的正式品牌文件
- Logo 固定右上角，不由模型重新绘制
- 图片模型只生成无文字主视觉
- 产品名称、数字、来源、标题和正文全部由模板排版
- 不伪造产品截图、官方 UI、财务图表、客户名单、合作关系或统计数字
- 来源在海报上只显示发布方简称，完整 URL 保留在来源 JSON

## 预览与正式资产

`--allow-placeholder` 只允许生成内部预览：

- `preview_only=true`
- 测试 Logo 必须明确包含测试标识
- 主视觉占位图必须明确标记不可发布
- 预览资产不能进入多平台分发

正式资产要求：

- `review_status=approved`
- `publication_allowed=true`
- 正式 Logo 存在
- 每条详情海报主视觉存在
- SVG 和 PNG 均为 2160×3840
- 无文本溢出、无占位符、无哈希错误
- Logo、日期、编号、来源和正文与 `briefing.json` 一致

## 生产原则

> AI 生视觉，模板排文字，程序做质检，人工做最终品牌审核。

具体命令、队列结构和 Manifest 见 `docs/VISUAL-PIPELINE.md`。
